# crypto-service-sdk-cpp 0.0.40

The first release of the C++ client, in lockstep with the Crypto
Service ecosystem's 0.0.40. The release workflow reads the Highlights
below and adds the pull requests, checksums and changelog link.

## Highlights ⭐️

* **A typed C++17 client for crypto-server**: one method per v2 operation (59 of 59) plus the probes and compliance documents, proven against the server by the crypto-service conformance kit (119 vectors) in CI.
* **Async first**: `AsyncClient` returns a `std::future` for every operation from one owned event-loop thread over a libcurl multi handle; `Client` is the blocking equivalent.
* **The shared resilience contract**: per-attempt timeout, overall deadline, opt-in retries with full jitter and `Retry-After`, no retry of stateful operations after a 504 or lost connection, W3C traceparent, cancellation, RFC 9457 problems in `ApiError`.
* **`find_package(crypto_service_sdk 0.0.40 CONFIG)`**: `cmake --install` exports `crypto_service::sdk`, and the release carries a source archive, a CycloneDX SBOM, SHA256SUMS and a provenance attestation.
